# Joseph Persteins - Personal Website

This is my personal portfolio website showcasing my projects and providing information about me.

## Website Structure

- **index.html** - Main HTML file
- **style.css** - Styling and responsive design

## Sections

- **Hero** - Landing section with introduction
- **About** - Information about me
- **Projects** - Showcase of my work
- **Contact** - Ways to get in touch

## Customization

Feel free to edit the content in `index.html` to personalize:
- Update the hero section with your own title and subtitle
- Modify the About section with your bio
- Add your actual projects in the Projects section
- Update contact links with your real social media profiles

## Deployment

This site is deployed using GitHub Pages at: `https://josephperst.github.io/joseph-persteins/`
